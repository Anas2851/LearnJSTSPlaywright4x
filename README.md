# Learn JSTS

A beginner-friendly collection of JavaScript fundamentals and prompt-engineering lessons, examples, and practice material.

## Lessons

### Prompt engineering

The [prompt engineering lessons](./01_Prompt%20Engineering/00_Prompt%20engineering/) cover:

- [RICE-POT: the prompt framework](./01_Prompt%20Engineering/00_Prompt%20engineering/00_RICE_POT_Fullform.md)
- [Writing a RICE-POT prompt](./01_Prompt%20Engineering/00_Prompt%20engineering/01_RICE_POT_Prompt.md)
- [Problem statements](./01_Prompt%20Engineering/00_Prompt%20engineering/02_Problem_Statement.md)
- [Avoiding hallucinations](./01_Prompt%20Engineering/00_Prompt%20engineering/03_Anti_Hallucination.md)

### JavaScript basics

The [JavaScript basics examples](./02_%20JS_Basics/) introduce output and arithmetic with [Hello World](./02_%20JS_Basics/00_Hello_world.js) and [math operations](./02_%20JS_Basics/01_Maths.js).

### Keywords and identifiers

The [keywords and identifiers examples](./03_JS_Keywords_identifiers/) cover the JavaScript engine, `let`, keywords, identifiers, naming rules, comments, and a practice quiz.

### Literals

The [JavaScript literals examples](./04_JS_Literals/) cover literal values, `null`, `undefined`, and a [numeric literal quiz](./04_JS_Literals/02_Literal_IQ.js) with integer, decimal, negative, and hexadecimal values.

## Run the JavaScript examples

Install [Node.js](https://nodejs.org/), then run an example from the project root:

```sh
node "02_ JS_Basics/00_Hello_world.js"
```

Replace the file path with another `.js` file in the lesson folders to explore a different example. The scripts print their results to the console.
